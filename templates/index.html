How it works

From question to cited answer

A retrieval pipeline built for technical documents, not generic web search.

Hybrid retrieval

Keyword search (BM25) and semantic vector search run together, so exact part numbers and related concepts are both found.

BM25 + HNSW · reciprocal rank fusion

Reranking

A cross-encoder rescores every candidate passage against your question and keeps only the most relevant evidence.

bge-reranker · fetch_k → top_k

The model writes a structured answer from that evidence only, and citation enforcement links each claim to its source report.
